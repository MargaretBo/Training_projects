
# Welcome to **C++ 3D Viewer**

Make yourself at home I guess.

### This program provides the ability to:
1. Load a wireframe model from an obj file (vertices and surfaces list support only);
2. Translate the model by a given distance in relation to the X, Y, Z axes;
3. Rotate the model by a given angle in relation to its X, Y, Z axes;
4. Scale the model by a given value;
5. Customize verteces, lines and background
6. Save your custom settings
7. Create bmp, jpg and gif files of the model
